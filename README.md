# Hit Colors

Hit Colors is a focused color contrast tool for checking text, background, and companion colors against WCAG contrast levels.

It helps designers and builders quickly test whether a color pair is readable, then keep a small set of supporting colors close by for interface work.

## Features

- Live foreground and background contrast preview
- HSL sliders and hex inputs
- Companion colors with WCAG contrast badges
- Random color generation that keeps the selected text/background pair usable
- Named color support for common CSS color names

## Getting Started

```bash
npm install
npm run dev
```

Then open the local URL printed by Vite.

## Build

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```
