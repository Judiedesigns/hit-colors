# Hit Colors

Hit Colors is a focused contrast tool for testing text, background, and companion colors against WCAG contrast levels.

## Features

- Live foreground and background contrast preview
- HSL sliders and hex inputs
- Companion colors with pass/fail contrast badges
- Random color generation that keeps the selected text/background pair usable
- Named color support for common CSS color names

## Development

```bash
npm install
npm run dev
```

Build for production:

```bash
npm run build
```
